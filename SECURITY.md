# Segurança

## Como reportar uma vulnerabilidade

Use a denúncia privada do GitHub: aba **Security** deste repositório, depois **Report a vulnerability**. Só quem mantém o projeto vê o relato.

Por favor, **não abra issue nem pull request público** com a falha.

Conte o que você viu, como reproduzir e a versão do Streemu.

## O que está no escopo

- O app Streemu para Android (o código está neste repositório) e o app de Windows ([Streemu/Streemu](https://github.com/Streemu/Streemu)).
- O servidor do grupo, que **não** está aqui. Falhas nele também podem ser reportadas pelo mesmo caminho.

## O que esperar

Lemos todo relato e respondemos pela própria denúncia. O projeto é mantido por poucas pessoas, então não prometemos prazo, mas falhas de segurança vêm antes de qualquer outro trabalho.
